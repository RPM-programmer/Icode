## These are interesting scripts for JS and Node.js

### You don't need to download anything for the scripts in the WEB folder.
### WEB folder:
- #### ConsoleStyle - Adds multiple colors.
##### This script adds multiple colors (supported by HTML) to the console.
- #### TemporalAPI - Simplifies working with the [Temporal API](https://metanit.com/web/javascript/28.1.php)
##### This script converts the Temporal API output string into a class (day, mounth, years; miliseks, sexes, minutes, hours).
- #### themesOnHtml - Adds themes to a web page.
##### The sample code was taken from the website - [metanit.com](https://metanit.com/web/html5/14.2.php)!
### NodeJs Folder:
- #### NodeJsProgressBar - Simplifies using the [progress module](https://github.com/visionmedia/node-progress)
##### This script requires downloading the progress module via npm (Node Package Manager). Command:
##### ***npm install --save progress***
- #### NodeJsSendFunction - Simplifies sending files over HTTP
##### You don't need to download anything for this script; everything is already included in the built-in HTTP module.
- #### NodeJsTerminalStyle - Simplifies using the [chalk module](https://github.com/chalk/chalk)
##### This script requires downloading the progress module via npm (Node Package Manager). Command:
##### ***npm install --save chalk***
